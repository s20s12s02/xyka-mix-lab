# Исследовательская база

Дата проверки: 2026-08-22.

## Технология XYKA PRO

- [Официальная инструкция](https://xyka.pro/manual): ручной режим 220–315 °C; смесь укладывается рыхло, чтобы сохранить свободную тягу.
- [Официальная рубрика `#XYKA_забивки`](https://t.me/s/xyka_pro?q=%23XYKA_%D0%B7%D0%B0%D0%B8%D0%B2%D0%BA%D0%B8): температурные сценарии конкретных линеек. Зафиксированы ориентиры Banger 310→270 °C; Bonche 315→280 °C; Xperience/Darkside 315→280–285 °C. Эти режимы используются как стартовые ориентиры и сопровождаются указанием следить за перегревом.

## Вкусовые сочетания

- [`#ванязабей`](https://t.me/s/vanyazabeygroop), включая `#микс`, `#чай`, `#ягоды`, `#напиток`, `#кондитерка` и брендовые теги. Из канала берутся вкусовая логика, роли и пропорции, но не угольный нагрев.
- Подтверждённые идеи для адаптации: пряный чай + тропик + ягода 50/30/20; энергетик + малина + ананас 30/20/50; тёплый чай + карамельный фрукт + ягоды 40/20/40; десертная база + ванильный/сливочный акцент + ягода 50/10/40; яркий цитрус + ягодное послевкусие 50/20 с конфетной связкой 30.
- Рецепты, где ядро — алкоголь, лёд или мята, отбрасываются. Публикации пересказываются нейтрально.

## Оценки ингредиентов

- [HTReviews](https://htreviews.org/) используется для сверки описаний, количества голосов, отзывов и ощущаемой крепости конкретного табака.
- Оценка HTReviews не переносится на рецепт целиком.
- Крепость линии сначала калибруется по сырью и классу продукта, затем сдвигается отзывами не более чем на один внутренний балл.
