# Surface brief — мобильная рецептурная

## Режим и задача

Operate. Совершеннолетний пользователь на iPhone выбирает направление и словесную крепость, получает рецепты только из своей полки и готовит 10 г в XYKA PRO.

## Утверждённая композиция

Источник: `.impeccable/mocks/option-b-step-ledger.png`.

Выбрана двухступенчатая журнальная композиция: узкая левая рейка фиксирует «1 Вкус / 2 Крепость», справа расположены восемь крупных вкладок направлений, ниже — полноширинные словесные категории крепости. Панель действия завершает рабочий лист, а результат начинается сразу под ней. На широком экране структура раскрывается в две колонки: фильтры слева, выдача справа.

## Инвентарь реализации

| Элемент | Материал/язык | Реализация |
|---|---|---|
| Фон | тёплая бумага, слабая координатная сетка | CSS, без растрового ассета |
| Заголовок | узкий тяжёлый редакционный гротеск | системный `Arial Narrow`/`Avenir Next Condensed`, fallback sans-serif |
| Рейка шагов | чернильная линия, круглые номера | семантический HTML + CSS |
| Вкладки направлений | бумажные индексные ярлыки, срезанные верхние углы | кнопки + CSS `clip-path` с прямоугольным fallback |
| Крепость | спокойные полноширинные строки | radio-кнопки с крупными label |
| Основное действие | сливовый штамп-плашка | button + CSS, без изображения |
| Карточка рецепта | лист рецептурного журнала, штамп происхождения | article + CSS |
| Иконки | линейные служебные знаки | встроенный SVG с `currentColor` |

## Не переносить буквально

Демонстрационные ингредиенты, проценты, граммы и число найденных миксов из изображения не являются данными. Декоративный клипборд и ботанические картинки упрощаются до кодовых линий/иконок, чтобы финальный HTML оставался лёгким и автономным. Текст и доступность управляются кодом, а не растром.
