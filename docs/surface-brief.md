# Surface brief — MixLab

## Режим и задача

Operate. Совершеннолетний пользователь на iPhone выбирает направление и словесную крепость, получает рецепты только из своей полки и готовит 10 г в XYKA PRO.

## Утверждённая композиция

Источники: утверждённый спокойный вариант 3 и финальный референс дыма/диаграммы из ImageGen.

Выбрана последовательная композиция. При первом открытии видны только шесть иллюстрированных направлений. После выбора направление сворачивается в постоянную строку с действием «Изменить», ниже появляется крепость с активным по умолчанию вариантом «Не важно». Результаты пересчитываются автоматически; отдельной кнопки подтверждения нет. На широком экране выбор становится липкой левой колонкой, выдача — правой.

## Инвентарь реализации

| Элемент | Материал/язык | Реализация |
|---|---|---|
| Фон | спокойная светлая бумага без фактурного шума | CSS |
| Заголовок | узкий тяжёлый редакционный гротеск | системный `Arial Narrow`/`Avenir Next Condensed`, fallback sans-serif |
| Направления | шесть гравюрных символов | кнопки + встроенные WebP |
| Крепость | пять дымовых состояний | кнопки + встроенные WebP, подпись и цвет |
| Случайный рецепт | спокойная контурная кнопка | button + CSS, без отдельного submit-действия |
| Карточка микса | плоский лабораторный лист | говорящее название без hook, точное SVG-кольцо + динамический коллаж WebP ингредиентов |
| Укладка | капсула сверху или сбоку | SVG-сектора с внешними иконками / пропорциональные CSS-слои с пояснением переворота |
| Иконки | 26 вкусов, 6 направлений, 5 уровней дыма | WebP data URI по asset manifest |

## Зафиксированные цвета

- Бумажный лист: `#FBF6EA`
- Чернила: `#25221F`

- Малина: `#B94E6E`
- Чайный зелёный: `#536B58`
- Латунь: `#B48A52`

## Не переносить буквально

Демонстрационные названия и доли из референса не являются данными. Проценты, цвета сегментов, легенда и порядок компонентов всегда строятся из `recipes.json`/`inventory.json`; растр отвечает только за образ вкуса. Источники, происхождение, ограничения и аллергены в UI не выводятся.
