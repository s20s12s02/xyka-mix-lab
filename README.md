# Моя рецептурная — XYKA PRO

Автономный русскоязычный подборщик миксов только из личной коллекции из 26 табаков. Пользователь выбирает вкусовое направление и словесную крепость, отключает закончившиеся вкусы и получает технологическую карту на 10 г для XYKA PRO.

## Онлайн-версия

[Открыть приложение через GitHub Pages](https://s20s12s02.github.io/xyka-mix-lab/)

На iPhone используйте эту HTTPS-ссылку: она открывается в Safari как обычный сайт и не зависит от ограничений Quick Look для локальных HTML-файлов.

## Готовый файл

`dist/xyka_mix_lab_2026-08-22.html` — переносимая версия для компьютера. Корневой `index.html` — идентичная публикационная копия для GitHub Pages. В оба файла встроены стили, шрифт, JavaScript, инвентарь, аналоги и 216 рецептов.

### Компьютер

Откройте HTML двойным кликом в Chrome, Safari, Firefox или Edge. Локальный сервер не требуется.

### iPhone

1. Перенесите `xyka_mix_lab_2026-08-22.html` в iCloud Drive или «На iPhone» через AirDrop/Файлы.
2. Коснитесь файла в приложении «Файлы».
3. Если iOS показывает статический Quick Look вместо интерактивной страницы, используйте «Поделиться» → открыть в Safari.
4. Избранное, отметки «Пробовал» и состав полки сохраняются локально на устройстве под ключом `xyka-mix-lab:v1`.

## Что внутри

- 8 направлений: десерт, тропики, ягоды, цитрус, чай, напитки, цветы, необычное;
- 4 доступные словесные категории крепости без вывода внутренней шкалы;
- 216 уникальных рецептов: 191 авторский, 7 адаптированных из открытых идей и 18 экспериментальных;
- 2–4 компонента, доли кратны 5%, проценты и граммы на 10 г;
- старт, середина и послевкусие, аргументация сочетания, укладка и нагрев XYKA PRO;
- явное происхождение и таблица замен для адаптированных рецептов;
- поиск, фильтры, «Моя полка», избранное и журнал проб;
- светлая/тёмная тема, safe-area и touch-target не меньше 44 px.

Числовой индекс крепости хранится только внутри JSON и расчётов. Пользователь всегда видит слова: «Лёгкая», «Средне-лёгкая», «Средняя» или «Крепкая». Категория «Очень крепкая» не показывается, потому что в коллекции нет подходящих табаков или миксов.

## Сборка и проверки

Требуется Python 3 и Node.js; сторонние пакеты для сборки не нужны.

```bash
python3 scripts/generate_data.py
python3 -m unittest -v tests/test_data.py tests/test_build.py
node tests/core_behavior.mjs
python3 scripts/build_html.py
```

Генератор детерминирован: повторная сборка создаёт те же данные, версионированный HTML и побитно одинаковый корневой `index.html` при неизменных исходниках.

## Структура

- `data/` — инвентарь, аналоговые замены и рецепты;
- `scripts/` — детерминированная генерация данных и сборка одного HTML;
- `src/` — семантический HTML, CSS, ядро фильтрации и интерфейс;
- `tests/` — контракты данных, автономности и поведения;
- `research/` — исходные фото и индекс источников;
- `docs/` — продуктовые и data-контракты;
- `qa/` — скриншоты, результаты ревизии и QA-протокол;
- `.impeccable/` — утверждённые макеты и запись дизайн-системы;
- `DESIGN.md` — визуальная система, извлечённая из готового интерфейса.

## Источники и ограничения

Технология забивки и температуры основаны на официальной инструкции XYKA PRO и публикациях `#XYKA_забивки`. Вкусовые идеи сверялись с `#ванязабей`; оценки и ощущаемая крепость отдельных табаков — с HTReviews. Подробности и дата проверки находятся в `research/sources/README.md`.

Алкогольные, ментоловые, ледяные и экстремально гастрономические профили исключены. Приложение предназначено только для совершеннолетних; никотин вызывает зависимость, а восприятие вкуса и крепости индивидуально.
