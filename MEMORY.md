# MEMORY.md — состояние проекта

Обновлено: 2026-08-23

## Цель

Создать один автономный HTML-подборщик миксов для XYKA PRO, открывающийся с компьютера и iPhone. Пользователь выбирает вкусовое направление и словесную крепость, а приложение предлагает рецепты только из его текущей коллекции.

## Подтверждённые решения

- Рабочий каталог: `/Users/ssshevtsov/ClaudeCode/Hookah/Mix`.
- Финальный формат: один автономный HTML без CDN и фоновых запросов.
- Визуальная концепция: «Рецептурная мастерская», макет до кода.
- Минимум 180 уникальных рецептов.
- Пропорции отображаются в процентах и граммах на 10 г.
- Состояние: наличие табаков, избранное и «пробовал».
- Крепость рассчитывается внутренне по шкале 1–10, но в интерфейсе показывается только словами.
- Алкоголь, лёд, ментол, выраженный холодок и экстремальная гастрономия исключены.
- Источники рецептов помечаются как exact, adapted, authored или experimental.
- Канал `@vanyazabeygroop` анализируется как один из основных источников вкусовых сочетаний.

## Текущий этап

- Базовые управляющие файлы были созданы первыми и проверены до появления остальных материалов.
- Продуктовая спецификация, data-контракт, исследовательский индекс и семь исходных фото зафиксированы.
- Из трёх мобильных компов реализован `.impeccable/mocks/option-b-step-ledger.png`; демонстрационные ингредиенты изображения в данные не переносились.
- Сгенерированы и провалидированы 26 табаков, 15 аналогов и 216 рецептов.
- Реализованы подбор, случайный рецепт, точные фильтры, полка, избранное, «Пробовал», подробная технологическая карта и fallback для `localStorage`.
- Финальный автономный файл собран: `dist/xyka_mix_lab_2026-08-22.html`.
- Автоматические тесты: 15 Python `OK`, JS `core behavior ok`.
- Браузерная QA пройдена на 1440×900, 390×844 и 375×844, в светлой/тёмной темах; overflow 0, консоль чистая, внешних ресурсных запросов нет.
- Прямой запуск HTML через `file://` подтверждён в Chrome; встроенные данные и JavaScript работают без сервера.
- Финальная дизайн-ревизия закрыта с verdict `ship`; фактическая система записана в `DESIGN.md` и `.impeccable/design.json`.
- Из-за ограничений открытия локального HTML на iPhone добавлена GitHub Pages-сборка: корневой `index.html` побитно совпадает с файлом в `dist/`; контракт защищён 16-м Python-тестом.
- Локальный Git-репозиторий `main` инициализирован, GitHub CLI повторно авторизован как `s20s12s02`.

- Sebero Classic должен оставаться в лёгком/средне-лёгком диапазоне.
- Dogma и Kraken не должны занижаться до среднего.
